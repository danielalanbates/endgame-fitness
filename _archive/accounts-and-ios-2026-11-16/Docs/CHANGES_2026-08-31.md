## TASK 2: Raid Cosmetics & Feed Integration ✅ (Wired)

### Problem
Raid victory (`raid_defeated`) already flows to feed as ActivityItem, but the reward cosmetic/title are never applied to the player profile. Backend returns them; client wasn't decoding.

### Solution
**GameProfile.swift:**

1. **RaidHit struct (lines 584–606):** Added two new optional fields:
   ```swift
   var rewardTitle: String?      // e.g., "Plate Liberator"
   var rewardCosmetic: String?   // e.g., "aura_iron"
   ```
   Both fields are in the sync response's `raid` object (decoded via CodingKeys).

2. **Sync handler (lines 786–789):** When a raid is `justDefeated`, apply the reward title to the profile:
   ```swift
   if hit.justDefeated, let rewardTitle = hit.rewardTitle, !rewardTitle.isEmpty {
       profile?.title = rewardTitle
   }
   ```
   The profile's `rankTitle` computed property already checks `title` first (line 87).

3. **Feed display:** `ActivityItem` already has `raid_defeated` kind with icon `bolt.shield.fill` and orange tint. No changes needed; ActivityRow renders it correctly.
